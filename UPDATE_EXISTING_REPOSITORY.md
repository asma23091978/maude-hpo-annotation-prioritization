# Updating the existing GitHub repository

Use GitHub Desktop because the update includes additions, replacements, moves,
and deletions.

1. Open GitHub Desktop and choose **File > Clone repository**.
2. Clone `asma23091978/maude-hpo-annotation-prioritization`.
3. Open the cloned local folder.
4. Delete its contents, but keep the hidden `.git` directory.
5. Copy into it all contents of this updated package.
6. Return to GitHub Desktop and review the changes.
7. Commit with: `Reorganize repository and add reproducible Stage 2 pipeline`.
8. Click **Push origin**.

Do not upload this ZIP as one file. Extract it first.
