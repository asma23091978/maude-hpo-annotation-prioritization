# Raw source data kept outside this GitHub package

The supplied `Maude_Guihub.zip` contains source exports used during construction, including
`Data_Stage2/Data_construction/en_product1.xml`, `en_product4.xml`,
`en_product6.xml`, `uniprotkb_taxonomy_id_9606_AND_reviewed_2025_12_27.tsv`,
`orphanet_disease_gene_hpo.csv`, several 35–61 MB intermediate datasets,
and other larger files. They are deliberately excluded here to keep the GitHub
repository compact. Preserve the original ZIP alongside a permanent archive
with provenance, retrieval dates, and licenses before claiming complete
raw-data reproducibility.

The compact integrated dataset `data/dataset_finale_Stoichiometry_CLEAN.csv.gz`
is the entry point for reproducing the published Python matching results.
